# AI.CO 週次検証（白島二・原田南）

箕面白島二丁目（白島二）と豊中原田南一丁目（原田南）の、AI.COカテゴリの週次レポート（お店づくりレポート②）と本部支援の検証レポートを、週ごとに積み上げて比べるページです。GitHub Pages でそのまま開けます。

> このリポジトリは公開です。実データは `data.enc.js` に暗号化して置き、ページでパスワードが合ったときだけ復号します。平文のデータや元のPDFは置いていません（`.gitignore` で除外）。

## 構成

| パス | 内容 |
|---|---|
| `index.html` | ページ本体（タブ：サマリー／週別の比較／改善シミュレーション／本部支援／店舗別／月次／ドライバ検証／見方と所見） |
| `data.enc.js` | 暗号化したデータ |
| `tools/build_site_data.mjs` | データ（JSON）を暗号化して `data.enc.js` を作るツール |

## 毎週の更新

1. 各店の「お店づくりレポート②」から、前週欄（週）と当月欄（月の累計）を読み取り、JSONに追加する。
2. 暗号化ファイルを作り直してコミットする（パスワードはリポジトリに書かない）。

```
AICO_PASSWORD=（パスワード） node tools/build_site_data.mjs data data.enc.js
```

月次検証レポートのグラフ（`monthly_trend`）はこの2店ではまだないため、月次タブのそのグラフは表示しません。
